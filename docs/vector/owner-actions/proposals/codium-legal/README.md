# Archived Codium legal proposal

On 14 November 2026, the owner chose to preserve the current live policies and archive the proposed changes for review.
This directory preserves the exact source changes from `94a5004ed4cb5742842befc2a553718f6c69e2d0`, on the
`codium-legal` branch whose tip was `fd4db7f47`. The later tip only records that the branch was pushed.

`94a5004ed.patch.gz` is a lossless gzip archive of the complete six-file patch, including its proposed consent
implementation, Terms and Privacy pages and tests. `archive.json` records its original base, source revision and both
compressed and uncompressed SHA-256 values. Compression preserves the patch's original context bytes on every platform.
These files are review material:
they are not application imports, build inputs or currently published policies.

Any later publication requires the owner's legal review and a separately reviewed release change. The draft's historical
date and proposed acceptance hashes must not be treated as approved current values. The integration does not modify
the live consent constant, current legal pages, or their active tests using this proposal.
