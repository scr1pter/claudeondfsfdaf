Work Vector repeats without you

An automation is one task Vector runs again and again on a schedule. Write the task, pick the repositories it runs in — and in each one whether it starts a new session or continues one you already have — then choose how often it repeats.

Across repositories
One task, one schedule, every repository you select. Each run reports back separately.
New or existing sessions
Keep adding to a thread you already started, or open a fresh session for every run.
While you are away
Vector stays in the tray after you close the window, so runs fire without you here.

Runs that fall due while Vector is fully closed are not replayed one by one — the next start catches up with a single run and says how many it skipped.
