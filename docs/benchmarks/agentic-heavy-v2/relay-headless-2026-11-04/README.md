## What the result establishes

The original Codex first submission passed 53/54 and its formal repair reached
the 300-request ceiling. Vector stopped before its original formal gate because
the next conservative request reservation could not fit the remaining shared
authorization. Its final exported source was subsequently evaluated for free
using the same frozen independent gate: 53/54. This diagnostic changed no authored
source and does not relabel the original `not_run` result as a passed submission.

Both final products denied the bootstrap credential on workspace business routes
with HTTP 403. The evaluator expected 401. A separate seven-case transport probe
isolated that status-code difference; both passed all six other probes. The
requirements call the bootstrap token an administrator capability, require 403
for a disallowed role, and disallow its business access without explicitly
assigning that special case a status. Keep the original failed assertion and this
interpretation limit. It is not evidence of unauthorized access.

The original frozen auditor also returned `StudyError`. A read-only Codex
reproduction identified its frozen-input manifest rejecting internal reparse
entries in mutable synthetic runtime fixtures. Later bounded support inventory
and native-command normalization corrections apply prospectively. They do not
retroactively pass either original audit or remove any other review observation.

## Cost investigation

`cost-drivers.json` reconciles every scoped receipt, including 39 Codex charges
without a unique native-transcript join. No charge is removed for an incomplete
join. Its classifications are descriptive heuristics, not proof that a tool call
was unnecessary.

Vector generated 276,110 output tokens versus Codex's 147,744. Reasoning tokens
(114,422 versus 42,851) are **included** in output, not added to it. The $2.0357956
episode-cost difference decomposes into $1.2836600 more output cost, $0.5450625
more cache writes, $0.3317151 more cache reads, and $0.1246420 less ordinary input
cost. Both runtimes retained one stable cache key per role and observed cache
reads. These traces do not support a cache-key-churn diagnosis.

The ten Vector wait-only turns account for $0.0941166, about 1.42% of its episode
cost. Some waiting is useful; only two immediate timeout-to-timeout pairs were
observed. Removing that entire category would neither be a justified quality
preserving change nor explain the larger cost difference. Likewise, repeated
commands may be productive verification or mutations rather than waste.

The original conservative reservation uses serialized UTF-8 bytes as a text
token upper bound. Ten admitted Vector lead requests reached its full-context
reservation without an image. The final rejected body was not retained, so its
exact contents are unknown. The stop establishes insufficient single-call
reservation headroom, not an image-triggered stop or actual token exhaustion.

The separate cancellation-accounting defect found during follow-up source review
is not credited with recovering any of this cost. The closed Vector trace has no
disconnected provider request. Subsequent production corrections and validation
are recorded under their own revisions.

## Separate post-run durability adjudication

Both blinded reviewers independently identified possible acknowledged-state
rollback in Codex's generated journal recovery. After their scores were locked,
`tail-diagnostic.py` applied the same three damage cases to fresh synthetic
directories for both unchanged final products. It first committed one member and
observed version 1, then gracefully stopped the service and removed, emptied, or
removed one complete final record from the documented journal.

Vector refused startup with its own nonzero exit in all three cases. Codex
announced readiness in all three: the missing/empty cases lost the workspace's
capability authority, and the valid-prefix case returned version 0 with no member
despite the previously acknowledged commit. The observer distinguishes natural
startup refusal from a test cleanup kill. All 45 source hashes still match the
closed manifests; no model, browser or external service was called.

These six observations are **post-run adjudication**, not preregistered acceptance
checks or additional points. Original 53/54 diagnostics, original native audit
flags and both reviewers' original scores remain unchanged. See
`tail-diagnostic.json` and `tail-diagnostic-provenance.json`. This narrow result
does not establish general product reliability or security certification.
