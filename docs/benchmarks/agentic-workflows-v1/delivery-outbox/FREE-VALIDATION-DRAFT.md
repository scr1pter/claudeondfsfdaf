# Free validation — draft only

This task is **not frozen, not runtime-qualified, and not admitted for paid use**. Its author did not inspect production candidates, optimization hypotheses, paid outputs or comparison reports. No model/provider calls, Bun invocation, dependency installation, application/fixture server, browser, build, typecheck, git mutation or publication has been performed while authoring this draft. The coordinating agent owns the exclusive Bun execution slot.

The only executed validation is `python -B tools/free_validate.py`, a pure Python control suite. Its latest result is 41 controls passed, zero failures and zero errors. Controls include positive accepted/retried/cancelled traces; negative duplicate-effect, changed-key, changed-wire-body, fabricated-receipt, missing-work and incorrect-attempt traces; complete versus incomplete report classification; exact generated-directory exclusions; LF-byte checks; rejected-output safety; read-only reproducible freeze previews; and freeze guards. A freeze round-trip control uses a separate temporary one-file synthetic fixture, never this benchmark directory. No `FREEZE-v1.json` exists for the task.

The authored independent inventory is 18 API groups and 8 browser checks. Its cardinality, handler counts, unique names, descriptor placeholders, protected-file existence and environment allowlist are checked by pure controls. Every evaluator report must have the complete inventory in its fixed order. Failure to run a browser or fixture is an instrumentation failure, never a silent pass. Product behavior assertions and invalid app responses are product failures; fixture control failures, browser startup/transport faults, occupied application ports, incomplete reports, unexpected evaluator exceptions and source-integrity violations are instrumentation failures. An observed product failure can leave later assertions in that group unexecuted, while every group still receives a report row.

All authored files use UTF-8 LF bytes, enforced by the task-local `.gitattributes`. The versioned helper hashes actual bytes with portable relative paths and a sorted canonical SHA-256 digest. It refuses CRLF input, linked source, duplicate final manifests and final freezing without an exact candidate reference plus an operator review/runtime-evidence record. Running its default preview does not write a file and does not authorize an experiment. The production candidate must be frozen before task details are reviewed by the candidate author and before the task itself is frozen.
