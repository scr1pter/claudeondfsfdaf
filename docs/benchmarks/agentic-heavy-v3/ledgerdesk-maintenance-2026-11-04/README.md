episodes are closed with **189 known receipts totaling $3.7877571**. The actual
team lifecycles did not both complete, so this is **not a matched completed-team
efficiency result**.

## What happened

Codex submitted its first result and passed 53/54 checks. Its one permitted
same-session repair was interrupted by the reservation guard before it changed
the source. First and final source manifests are identical. Vector stopped on
reservation affordability after its five implementation roles; independent QA and
the judge had not started. Its original formal gate remains `not_run`. A separate
free evaluation of the unchanged exported source subsequently passed 53/54.

Both generated applications rejected an access-key scope containing a nonexistent
account with HTTP 404; the frozen evaluator expected 400. A separate five-case
diagnostic isolated that difference and observed the four other management
controls passing. Neither invalid scope was accepted. Original failed checks,
original audit flags and reviewer scores remain unchanged.

The two reviewers scored exact randomized A/B source copies before learning the
mapping, costs or outcomes. Their prior task/instrument familiarity and static
review limits are preserved in the locked files. Reviewers independently found
an original-invoice replay issue after credits in Vector's generated code. One
also noted non-fatal UTF-8 decoding in Codex's output. These are bounded static
findings, not security certification or claims about the coding products
themselves. No benchmark app was manually repaired to improve the reported score.

The lower Vector cost cannot establish equal-quality savings: its two
verification roles never ran, the source reviews scored it lower, and neither
original run satisfied the full functional and execution criteria. Preserve this
limitation alongside the attractive cost number.
