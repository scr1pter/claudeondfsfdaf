# Retired synthetic reference implementations

These reference solutions and their available qualification recipes were
withheld from paid model agents. They were released after all study API work
closed, the key-holding gateway exited, and both final blinded source reviews
were locked. The release manifest preserves exact source hashes.
Original CRLF and final empty lines are retained; fixture-specific whitespace
attributes preserve those bytes without changing production source rules.

- `harbor-ui` is the reference UI/API application from the interrupted Harbor
  study. Its source and lockfile are included; dependencies and build output are
  excluded.
- `relay-headless` contains the reference roster service, CLI, typed SDK,
  storage contract and positive/mutant qualification recipe.
- `ledgerdesk-maintenance` contains the reference maintenance solution and its
  positive/working-seed/mutant qualification recipe.

Use these as reproducible regression fixtures. Their publication retires these
cases from future claims of unseen holdout performance. Reference code is an
evaluation instrument over synthetic data, not the Vector product. Original
requirements, evaluator corrections, qualification records, failed runs and
produced model outputs remain separate evidence.

No model weights, credentials, company documents, dependency trees or private
reasoning transcripts are part of this release.
