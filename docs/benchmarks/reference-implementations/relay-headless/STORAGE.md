Journal: journal.jsonl

Each newline-terminated transaction is `{seq,previous,state,hash}`. Sequence starts at 1; previous is 64 zeros for the first transaction. Hash is SHA256 over canonical JSON of the other three fields (recursively sorted object keys, array order preserved). Each full state commits directory, capabilities, imports, replay results and events atomically. Every append is flushed with fsync before publication. The identity file prevents missing journals from becoming empty state. A writer.lock directory contains the owning PID and random nonce; live or ambiguous owners fail closed, a proven dead PID can be reclaimed. Only the current nonce owner removes its own lock. Shutdown on owning stdin drains writes. Runtime data and reference code are outside the candidate task root.
