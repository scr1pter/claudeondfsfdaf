# Foundry blinded visual review

Review opaque arm labels without runtime/cost information. Score only delivered evidence; retain screenshots, viewport, route/state and reasons. Do not infer functionality from a polished screenshot. Functional gates and this visual score are separate.

For each axis use0 missing/broken,1 weak,2 competent,3 polished,4 exceptional. Ten axes, maximum40; no automatic screenshot score.

1. Coherent Foundry identity: restrained palette, typography, icons and visual language across domains.
2. Information hierarchy: overview prioritizes actual business state; dense detail remains readable.
3. Navigation and workspace context: orientation, current workspace/role and task transitions are clear.
4. Tables and forms: readable alignment, useful density, validation and action placement.
5. Order-to-invoice workflow: quantities, status, money and snapshots are understandable without technical knowledge.
6. Project board and collaboration: task status/priority/assignees/comments remain legible and usable.
7. Interaction finish: clear loading, empty, success/error, disabled and destructive states.
8. Mobile composition: useful390px layouts, navigation, contained scrolling and touch controls.
9. Accessibility: contrast, visible focus, labels, dialog behavior and keyboard usability.
10. Overall craft and originality: a convincing connected business product, avoiding generic dashboard filler or invented chart data.

Capture desktop overview/customers/inventory/project-board and mobile overview/customers/inventory/orders/project-board where available. Missing evidence is recorded as missing, not zero-cost success. Inspect full screenshots at native size. Compare both arms using the same rubric, without adjusting scores to fit spend or speed.
